# /i-have-adhd - ADHD Output Optimization

$ARGUMENTS

---

## Purpose

Activates an executive-function optimized output style:
1. Puts the next action on the very first line (command, file, snippet).
2. Numbers all multi-step actions into single-step items.
3. Suppresses tangents until the primary goal is achieved.
4. Restates state on every turn (`Current state: ... Pending: ...`).
5. Ends with exactly one concrete action under 2 minutes.

---

## Usage

| Command | Action |
|---------|--------|
| `/i-have-adhd` | Activate ADHD mode for the remainder of the session. |
| `stop adhd mode` | Deactivate ADHD mode and revert to standard style. |
| `normal mode` | Deactivate ADHD mode and revert to standard style. |
