# UI & UX Design Standards

## 1. 🚫 PURPLE BAN
- Strictly avoid generic violet/purple gradients and default indigo templates.
- Use curated, intentional palettes tailored to brand identity (deep slates, rich emeralds, warm ambers, crisp cyans, high-contrast dark modes).

## 2. 🎨 ANTI-CLICHÉ AESTHETICS
- No generic hero-with-centered-text templates.
- Use modern typography (Inter, Outfit, Plus Jakarta Sans) rather than browser defaults.
- Use smooth micro-interactions, subtle borders, and intentional white space.

## 3. 📱 TOUCH-FIRST ERGONOMICS (MOBILE)
- Minimum 48x48dp touch targets for interactive elements.
- Bottom-sheet and thumb-zone navigation for high-frequency mobile actions.
